Configuration

Set the server URL and credentials for your environment. Enable only the features your application needs.

Features

  • Request/response capture ring buffer for debugging
  • Idempotency keys for safe retries of mutating operations
  • Statistics capture: per-operation counters and latency
  • Pagination signals for list operations
  • Client-side rate limiting via a token bucket
  • Automatic retry of transient failures with exponential backoff
  • In-memory mock transport for testing without a live server
  • Per-request timeout with transport abort

Tools

hook0_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "application | application_secret | applications_management | event | event_type | events_management | events_per_day_entry | health | hook0 | ingested_event | instance | login | organization | organization_edit_role | problem | quota | registration | request_attempt | response | revoke | service_token | subscription | user_authentication | user_invitation"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: application, application_secret, event, event_type, events_management, events_per_day_entry, hook0, organization, problem, request_attempt, service_token, subscription.
