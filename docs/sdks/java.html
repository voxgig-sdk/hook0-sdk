Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import voxgig.hook0sdk.core.Hook0SDK;
import java.util.Map;

Map<String, Object> options = new java.util.LinkedHashMap<>();
options.put("apikey", System.getenv("HOOK0_APIKEY"));
Hook0SDK client = new Hook0SDK(options);
